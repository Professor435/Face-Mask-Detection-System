# Face-Mask-Detection-System
Face Mask Detection System — A real-time AI-powered web application that detects faces and classifies mask usage using TensorFlow.js. Features include live webcam monitoring, bounding box visualization, confidence scoring, detection logging, snapshot capture, sound alerts, and compliance analytics. Built with pure HTML5, CSS3, and vanilla JavaScript. No backend required — runs entirely in the browser. Perfect for entry screening, public safety monitoring, and health compliance checks.
